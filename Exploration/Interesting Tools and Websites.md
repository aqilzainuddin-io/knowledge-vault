**LENIS** [https://github.com/darkroomengineering/lenis]
----
*Normally when you scroll a webpage, the browser controls the movement directly. **lenis** sits on top of native scrolling and makes that movement feel smoother and more controlled.*

*Instead of:*
> *mouse wheel → page immediately jumps*

*you get something closer to:*

> *mouse wheel → smooth acceleration → smooth movement → smooth stop*

*It is lightweight, dependency-free, works with native browser scrolling, and is specifically designed to synchronize nicely with things like WebGL, parallax effects, and gsap ScrollTrigger.*


**GSAP** [https://github.com/greensock/GSAP]
----
***Gsap**, or GreenSock Animation Platform, is much broader.*
*It is essentially an **animation engine for javascript**.*

*Gsap can animate CSS, SVG, canvas, React components, WebGL objects, colors, motion paths, and many other properties. It also has **ScrollTrigger**, which lets animations respond to scrolling.*

*This is also why you'll frequently see **lenis + gsap together**. lenis's own documentation even includes an integration specifically for gsap ScrollTrigger.*


**VANTA** [https://github.com/tengbao/vanta]
----
*It gives you **animated 3d/WebGL backgrounds** without requiring you to build the graphics yourself.*

*Vanta provides predefined effects and renders them using three.js/WebGL or p5.js. It works with vanilla javascript as well as React, Vue, Angular, etc.*


**REACT-BITS** [https://github.com/DavidHDev/react-bits]
----
***react bits is a collection of reusable React components.***

*Instead of programming an animation yourself, you can take an existing component and customize it.*

*It currently provides a large collection of things such as text animations, UI components, animations, and animated backgrounds, with javascript/typescript and CSS/Tailwind variants.*


**SPLINE** [spline.design]
----
*Spline describes itself as a browser-based collaborative tool for building production-ready real-time interactive 3d experiences. It supports modeling, materials, animation, physics, particles, states/events and web integration.*


**ACETERNITY UI** [ui.aceternity.com]
----
*Aceternity currently provides React/Next.js components, blocks and templates built around technologies including Tailwind CSS and Motion.*


**MANUS** [manus.im]
----
*Manus is an ai-agent platform. Its current product includes capabilities for building websites, creating slides, designing things, generating images/music, browser operation, research and more.*
